# Notebooks

- `moodmentor_reproduce_colab.ipynb`: a clean, ordered run that trains DistilBERT and BERT with the scripts in `ml/` and scores them on SemEval-2018 and ISEAR. Run it in Colab with a bundle made by `python -m ml.make_colab_bundle`.
- `archive/moodmentor_colab_working_log.ipynb`: the original working notebook, unedited. It contains the cells that produced the reported results, plus an early 6-class experiment and repeated cells. Kept for reference only.
